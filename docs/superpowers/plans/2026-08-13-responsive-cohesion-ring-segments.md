# Responsive Cohesion Ring Segments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace pill-shaped Ship Cohesion arcs with visually matched desktop/mobile annular sectors that have narrow radial cuts and approximately 2-pixel corner softening.

**Architecture:** Keep 20 logical `.ship-cohesion-segment` groups and the existing front/back SVG layers. Each logical segment owns desktop and mobile closed-path variants generated by one annular-sector geometry helper; CSS exposes the calibrated variant for the active viewport and applies state color, glow, preview, and queued treatment through the parent group.

**Tech Stack:** Browser-native SVG, JavaScript DOM rendering, responsive CSS, Node.js fake-DOM assertions, Playwright/Chromium visual certification.

## Global Constraints

- Render each segment as a closed annular sector with concentric outer and inner arcs, radial cut faces, and approximately 2 CSS pixels of optical corner softening.
- Preserve exactly 20 logical segments, their ordering, list semantics, labels, task bindings, state classes, interaction behavior, reduced-motion behavior, and front/behind-ship layer split.
- Target approximately 15-16 CSS pixels of visible band thickness at 1440 by 900 and 390 by 844.
- Desktop and mobile must share the same perceived silhouette; breakpoint-specific geometry is allowed only to compensate for the rendered ring diameter.
- Keep the existing ring orbit, ship framing, task cards, navigation, colors, and Cohesion rules unchanged.
- Preserve unrelated `debug.log`, `.codex-remote-attachments/`, and `docs/technical/STORY_DIRECTOR_TURN_FLOW.md` work.

- [ ] **Step 3: Implement the annular-sector geometry helper**

Replace `cohesionArcPath(index)` with a helper that computes rounded annular geometry. For each outer/inner radius, convert the corner distance into a small angular inset so the quadratic control point remains the original sharp polar intersection:

```js
function cohesionSegmentPath(index, {
  centerRadius,
  bandWidth,
  gapDegrees,
  cornerRadius,
}) {
  const center = 50;
  const outerRadius = centerRadius + (bandWidth / 2);
  const innerRadius = centerRadius - (bandWidth / 2);
  const slotDegrees = 18;
  const startAngle = -90 + (index * slotDegrees) + (gapDegrees / 2);
  const endAngle = -90 + ((index + 1) * slotDegrees) - (gapDegrees / 2);
  const outerInset = cornerRadius * (180 / Math.PI) / outerRadius;
  const innerInset = cornerRadius * (180 / Math.PI) / innerRadius;
  // Build M/Q/A/Q/L/Q/A/Q/L/Z from polar points rounded to three decimals.
}
```

The path traversal is: start radial face at `outerRadius - cornerRadius`; quadratic through the sharp outer-start corner; outer clockwise arc; quadratic through outer-end; radial line to `innerRadius + cornerRadius`; quadratic through inner-end; inner counter-clockwise arc; quadratic through inner-start; radial line back to the start; close.

```js
const item = createSvgElement('g', `ship-cohesion-segment ${stateClasses}`);
```
