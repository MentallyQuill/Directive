# First Campaign Workflow

1. Enable Directive in SillyTavern.
2. Click the ship icon next to the composer.
3. Open Campaign and select Ashes of Peace.
4. Finish the four character-creation steps and accept the dossier.
5. Let Directive create your campaign chat and open the opening scene.
6. Play in normal prose. No command syntax is required.
7. Swipe the assistant drafts until the one you want is selected.
8. Send your next message to accept the selected draft.
9. Keep Mission open for current objectives, hard deadlines, and outcomes.
10. Use People for crew background, ties, and your Command Bearing reserve.
11. Use Ship for the U.S.S. Breckenridge status, active limits, and what work is realistically available.
12. Do ship work in chat only. There is no “build this project” button.
13. Create a checkpoint before a major decision if you want a clean rollback point.
14. If you want to continue from a checkpoint, use Load Game. It opens a new continuation chat.

You do not need to tick boxes for normal story events.
Directive checks your chosen text against the mission rules and the current accepted game state.

Important: this is Alpha.
Systems and edge cases can change or break between updates.
