## Single scenario and phases

Use a fresh Ashes campaign and the first Hesperus mission's rescue objective as the principal correction target. Read its authored predicates and visible options first. Play a cooperative character; do not prompt-inject the narrator or announce unsupported successes. The broader 13-mission corpus already provides mechanical breadth; this one run measures a real interaction rather than claiming campaign-wide semantic coverage.

1. **Baseline and partial progress (roughly turns 1–6).** Capture initial Mission UI and canonical projection. Establish the mission naturally. Give a plan/order, then achieve a legitimate partial result such as stabilization while the authored rescue endpoint remains outstanding. Before each turn, privately record expected/forbidden changes without feeding those expectations to the narrator. Compare expectations with what the accepted narration actually establishes; narration may legitimately advance farther than the player's request. Check objective states, explanation excerpts, and notifications after every accepted pair. Record natural false positives and missed successes separately.
2. **Deterministic correction probe (roughly turns 7–10).** If a natural premature resolution occurs, reopen it through its notification or Mission control. If none occurs, use the actual Adjust progress UI to deliberately mark the partial objective complete, then reopen it as Still underway. Label this an injected UI decision, NOT a model false positive. Capture before/after state, accepted evidence and partial progress, rewards/dimensions, pending transition, and retired notifications. Keep other required objectives unfinished so this probe does not advance out of the mission.
3. **Durability and ordinary continued play (roughly turns 11–15).** Reload the browser on the same campaign. Confirm reopening and legitimate partial progress persist. Continue natural discussion of the same partial event and take an unrelated action. Old discussion must not restore completion or repeatedly notify. Also set an appropriate visible objective to an authored player-selected result where doing so will not close the mission; verify the Set by you state survives a subsequent interpretation and reload. Do not fabricate narrative facts to justify the manual selection. If no safe second target is available, use the primary target sequentially and document the order.
4. **Real success after reopening (roughly turns 16–22).** Carry out materially new action that actually meets the authored rescue endpoint in accepted narration. Check for a single nonblocking proposal with evidence, leave it pending for one ordinary turn, then accept it through the UI. Verify completion, notification behavior, and exactly-once reward/pending-transition effects. Reload once more and confirm persistence. If the model misses the real success, record the miss and use player correction to verify recovery; do not silently classify manual recovery as successful automatic detection.
5. **Finish within the cap (up to turns 23–24).** If the same trajectory naturally reaches a mission transition, verify stale controls cannot adjust the previous mission. Otherwise mark that integration point unexercised; do not manufacture completion of the rest of the campaign just to check a box. Capture final state and stop.

These turn ranges guide pacing, not instructions to force the story. Preserve the actual sequence and explain deviations. Resume-automatic, difficult source edits/swipes, and in-flight races may remain controlled-test-only in this bounded run. Do not claim they were live-tested unless actually exercised.
