# Bundled Breckenridge Package

Bundled U.S.S. Breckenridge campaign package and Ashes of Peace campaign data.

The package skeleton is `ashes-of-peace.campaign-package.json`.

`breckenridge-senior-staff.crew-dataset.json` contains seven senior officers and twenty supporting-character narration guides. Character references specify the performance qualities to borrow and the boundaries that preserve the original cast. Supporting entries do not automatically create People dossiers or establish scene presence.

See the [character reference sheet](../../../docs/source/Directive_Ashes_of_Peace_Character_References.md) for the complete assignments.
